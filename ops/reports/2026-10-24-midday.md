## Features
* **One-command install (#38).** `curl -fsSL .../install.sh | bash` works on Raspberry Pi OS and macOS. It sets up a private Python environment, adds the `mtdi` command, and can start MTDI at boot (`--autostart`) or remove it cleanly (`--uninstall`). It finishes by running `mtdi doctor`. Docs: `docs/INSTALL.md`.
* **`mtdi doctor`** checks Python, the packages, the engine, the worst-case speed at 128 channels (a warning, never a failure), the studio, serial ports including the Pi's UARTs, local or cloud AI, and disk space.
* **`mtdi studio`** opens the interface from any folder. Bundled projects load from anywhere.
* **Local AI on by default.** The installed launcher sets `MTDI_LOCAL_LLM=1`, so a Pi running Ollama answers offline with no extra step. If Ollama is down, the fallback takes about 0.03 s.
* **Studio project panel (#39, decided S1-11).** It reads the engine packet directly. It shows each channel's state, calibration, drift and its own SIMULATED label, plus fused estimates with the basis for each input.
