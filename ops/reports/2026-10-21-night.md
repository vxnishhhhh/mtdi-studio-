## New features
- **NVTRA can't quote a number it doesn't have.** If a model answer contains a number that isn't in the packet, the answer is thrown away and the rules answer is used. The note says which numbers were rejected.
- **`research sensor fusion`** (also `look up …` / `find papers on …`) returns real references from Crossref, arXiv and Wikipedia, labelled as reading material rather than measurements, and says which sources didn't answer.
- **NVTRA brand** is visible in the studio: the gold wing mark sits next to the wordmark.
- **Calibrated channels (PR #13, still in review, not on main yet):** fit a calibration once with `mtdi.fusion`, save it, and point the channel at the file. From then on every reading is corrected live. Raw values are kept, and the snapshot records which method was used and how far off it was.

## Ideas
- Validation could compare a calibrated channel's live residual with the residual stored at fit time and flag drift. This is the two-way Environmental ↔ Validation link from the brief.
- `mtdi calibrate <project> <channel> --reference file.csv` would turn the fit into one command.
