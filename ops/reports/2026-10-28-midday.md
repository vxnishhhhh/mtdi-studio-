## Features
* **Calibration stays with the input it was made for (#76).** A calibration records its input unit and whether it was made for a project feed or the studio's own source, and applies only to matching samples. The calibration form's unit starts blank, so the engine follows the live source.

## Bugs found and fixed
* **A calibration saved before the first sample applied to everything.** With no input recorded, a channel 1 calibration could rescale a cm feed and label it µT. It is now bound to the studio's own sources.
* **A skipped calibration was still reported as applied.** The snapshot said `calibrated: true` for samples whose profile ingest had skipped. It now reports what the latest sample used.
* **A new input was compared against the old one's baseline.** When a channel switched unit, or switched between a project feed and the studio's own source in the same unit, deviations were measured against the previous reference, which could raise false alerts. The baseline and history now reset on either change.
* **The calibration form started at uT.** On a cm feed, an untouched form submitted uT and labelled cm readings µT.

## Ideas
